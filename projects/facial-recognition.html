Custom Facial Recognition System

Developed a customizable facial recognition system using Xception transfer learning and a two-phase training strategy to identify specific individuals while gracefully handling unknown faces.

View on GitHubEmail me

Problem

Build a customizable facial recognition system that can be trained to recognize members of a specific group without relying on closed-source solutions, while handling outliers.

Data

Pre-prepared dataset with images organized per person plus an “Unknown” class. 30–50 images per person are recommended.

Approach

  • Transfer learning with Xception.
  • Custom head: GlobalAveragePooling2D → Dropout (0.5) → Dense (128, ReLU) → Dropout (0.3) → Output.
  • Two-phase training: frozen base first, then fine-tuning the top layers.
  • Automatic class weighting for imbalanced datasets.
  • Adjustable confidence threshold (default 0.7) for “Unknown” detection.

Stack

Technology
Python
TensorFlow
Keras
Xception
OpenCV
Streamlit

Results

A working Streamlit application supporting custom model training, real-time inference with confidence scores, training visualization and a face-capture utility.

What I’d improve

Add quantitative evaluation metrics (e.g., per-class precision, recall and F1-score) and a public demo deployment.
