Nigerian Business Finder

Built a location-aware Python web app that helps users discover nearby local businesses (like bukas and suya spots) using real-time API mapping.

View on GitHubEmail me

No hosted demo yet. Run it locally with streamlit run main.py.

Problem

Mainstream mapping services often lack tailored local categories (e.g., “buka”, “suya_spot”) and real-time location-aware navigation for Nigerian businesses.

Data

Live API queries to Geoapify (geocoding, places, directions) and Foursquare (ratings). The search radius defaults to 1,000 metres.

Approach

  • Built with object-oriented principles.
  • Fuzzy matching handles misspellings of local categories.
  • Interactive Folium maps show user and business markers connected by lines.
  • Browser geolocation provides real-time tracking.
  • Error handling for API failures.

Stack

Technology
Python
Streamlit
Folium
Geoapify API
Foursquare API

Results

A working Streamlit application that accepts manual or automatic location, supports Nigerian-specific categories, and provides turn-by-turn directions with walk and drive modes.

What I’d improve

Add a public demo deployment and include a sample .env.example file with clearer API-key onboarding to lower the barrier to evaluation.
