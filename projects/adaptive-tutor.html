Adaptive Intelligent Tutoring System (Final Year Project)

Engineered a personalized learning platform combining RAG for factual accuracy with Reinforcement Learning (RL) and Human-in-the-Loop feedback to dynamically adjust instruction.

View on GitHubEmail me

Problem

Traditional Intelligent Tutoring Systems often rely on rule-based strategies or performance metrics alone, which limits real-time adaptation. This framework combines Retrieval-Augmented Generation (RAG) with RL mechanisms driven by human-in-the-loop (HITL) feedback.

Data

Educational documents ingested into a vector store. An evaluation set exists in the repository (eval_dataset.json).

Approach

  • Modular Python application with FastAPI endpoints.
  • RAG pipeline uses LlamaIndex and LangChain to retrieve context and generate responses via Google Generative AI (Gemini).
  • An RL agent learns adaptive pedagogical strategies over time.
  • Evaluated using RAGAS metrics: faithfulness, answer relevance and context precision.

Stack

Technology

Results

A functional evaluation pipeline built on RAGAS. Evaluation artifacts in the repository show a quantitative assessment of the RAG pipeline.

What I’d improve

Strengthen the RL component with a proper learner-state model (e.g., Bayesian Knowledge Tracing) and offline, off-policy evaluation (doubly robust estimators) to make the “adaptive” claim empirically measurable and avoid risky exploration on real learners.
